# 성과·면담 관리 시스템 V4.1

관리자와 팀장만 로그인하고, 일반 팀원은 계정 없이 팀원 데이터로 관리하는 버전입니다.

## 권한
- 관리자: 전체 팀장 계정 승인·관리, 전체 팀원·성과·면담 조회 및 관리
- 팀장: 본인이 등록한 팀원, 목표, 면담만 관리
- 일반 직원: 로그인 계정 없음

## 주요 기능
- 팀원 추가·수정·퇴직 처리
- 관리자만 완전 삭제 가능
- 팀원별 목표·면담 연결
- 신규 가입 계정 기본값: 팀장 / 승인대기
- 관리자가 직원관리 화면에서 팀장 계정 승인 및 중지

## 기존 V4에서 업데이트
1. GitHub 파일을 V4.1 파일로 교체하고 커밋합니다.
2. Supabase SQL Editor에서 `supabase/migrate_v4_to_v4_1.sql`을 한 번 실행합니다.
3. Netlify는 GitHub 커밋을 감지해 자동 배포합니다.

> 마이그레이션 SQL은 초기 구축 단계 기준으로 기존 목표·면담 데이터를 비웁니다. 현재 입력된 목표·면담이 있다면 먼저 백업하세요.
